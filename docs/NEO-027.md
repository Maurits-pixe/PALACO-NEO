# NEO-027 — Independent OWNER + SECURITY approvals on key decisions (DRAFT)

## Added
- `keyQuorumPolicyDigest`: deterministic SHA-256 over an explicit versioned review policy, namespace, reviewer identity, role, status and Ed25519 verification keys. Rejects duplicate reviewer IDs and duplicate cryptographic keys, including aliases encoded as equivalent PEM.
- `keyQuorumReviewPayload`: domain-separated Ed25519 message binding one event's full NEO-026 chain hash, sequence, decision ID, reviewer identity/role and independently pinned policy digest.
- `verifyDualKeyDecisionReviews`: first re-verifies the entire NEO-026 signed governor decision chain against independent initial key history and trusted decision-head floor. Then requires exactly two active reviewers with different cryptographic keys and different roles: OWNER and SECURITY. Rejects missing, forged, duplicated or revoked reviews.
- Twelve regression tests cover valid dual-review, duplicate keys, one-role quorum, policy pin tampering, invalid governor signatures and malformed input.

## Restrictions and unresolved production requirements
All verification results carry `authorized:false`. Signature checks do not issue approvals or authorize execution, migration, deployment or merge.

Reviewers and governor keys MUST be independently authenticated and held outside the mutable repository. This is a **single policy snapshot**; no authenticated policy succession, revocation effective timestamps, hardware-backed identities, challenge freshness, two-person operational separation, four-eyes governance quorum escalation or trusted signing time is provided. The signed review alone does not prove the reviewer intended, understood or legally approved the decision. A reviewer key that is also held by a governor is not expressly prohibited in this draft; distinct OWNER/SECURITY reviewer keys are required.

The proof chain is not durably persisted here. No external API is contacted, no key authority established, and no production changes made. GO-13 HOLD and authorization DENY remain.
