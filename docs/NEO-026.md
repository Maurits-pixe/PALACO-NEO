# NEO-026 — Signed custodian key-decision chain (DRAFT)

## Delivered
- `keyDecisionPayload`: deterministic domain-separated bytes for ROTATE / COMPROMISE decisions, including custodian, old/new key-history digests, version, effective anchor revision, decision ID and preceding decision hash.
- `verifyKeyDecisionChain`: verifies every signed Ed25519 governance decision against externally pinned governor public keys and status; recomputes the complete key-history transition and rejects arbitrary mutations, duplicate decisions, broken hash links and rollback below independently retained count/head.
- Rotation delegates to NEO-025's exact cutover rules. Compromise changes a uniquely selected TRUSTED epoch to COMPROMISED, without silently enabling an alternative key.
- Twelve regression tests covering legitimate rotation and compromise, forged/revoked governor, corrupted history, stale floors and malformed inputs.

## Limits
The caller MUST authenticate and separately retain both initial key-history pin and trusted governance keys, as well as latest decision-ledger floor. The governor set is static in this draft; no authenticated governor succession, quorum policy, co-signature threshold or key-recovery authority is provided. A signature proves possession of the governor private key, not governance legality or real-world identity.

The effectiveRevision represents an externally trusted anchor revision, **not a timestamp** or proof of when the private key signed. Compromise is conservatively retroactive for the marked epoch. Signed events and checkpoints remain in memory only; no independent durable decision archive is implemented.

All successful results remain `authorized:false`; no merge, production deployment, key issuance, external write or autonomous decision. GO-13 HOLD / DENY.
