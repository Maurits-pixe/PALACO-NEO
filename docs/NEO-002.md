# PALACO-NEO — NEO-002 DRAFT: inspectable audit hash-chain

Offline, dependency-free (Node built-in crypto) audit *prototype*. No writes to disk, execution, Bluetooth, OS, identity integration or production authority.

## Usage
- `appendAudit(records, event)` constructs a new immutable record; caller retains full responsibility for storage.
- `verifyAudit(records, expectedHead?)` checks sequence numbers, fixed-field schema, previous hash links and recomputed SHA-256 hashes.
- `verifyCheckpoint(records, {head,count})` compares to an **independently trusted** anchor supplied by the caller.
- NEO-001 admission remains the only gate, with execute/publish DENY and GO-13 HOLD.

## Critical trust boundary
A self-computed hash chain is **not authentication**. An adversary who can rewrite the records can recompute all hashes. Without an external, immutable, trusted head, complete replacement or valid-prefix truncation is not detectable. This implementation does not claim durable storage, anti-replay across restarts, signatures, trusted time, tamper-proof audit or secure recovery. `verifyCheckpoint` cannot establish whether its input checkpoint is trustworthy.
