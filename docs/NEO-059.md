## Explicit trust boundaries
This is a **read-only cryptographic forensic verifier**. It cannot send incident notifications, decide which external state is true, close disputes, grant authority, revoke keys, create credentials, persist an immutable database or deploy any service. A valid Ed25519 signature establishes only a statement made by a key, not real-world identity or organizational independence. Input policy rosters and public keys must be independently authenticated; complete original evidence and monotonic trusted floors must be retained outside this process. Without a separately stored trusted floor, whole-history deletion or replacement cannot be reliably detected.

An empty incident register accepted against the genesis pin is not evidence no prior incidents existed. No `CLOSE`, `DISMISS`, `RESOLVE` or `RELEASE` action exists: all accepted incidents are permanently `ESCALATED_HOLD` in this schema. All results explicitly set `authorized:false`.
