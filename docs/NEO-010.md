# NEO-010 — Reviewer revocation & review evidence ledger (DRAFT)

## Modules
- `reviewerPolicyDigest`: deterministic policy snapshot digest, including reviewer roles and ACTIVE/REVOKED status.
- `proposeReviewedDecision`: requires pinned reviewer policy, two valid independently trusted OWNER + SECURITY signatures, and a ledger anchored by a caller-supplied trusted head. Revoked reviewers are excluded.
- `verifyReviewLedger`: fixed-schema SHA-256 chain checks and duplicate transition-ID checks.

## Trust boundary
All outcomes set `authorized:false`. Successful review produces only an immutable **candidate** entry, without committing it. Independent reviewer policy pins, reviewer identities and the previous ledger head MUST come from authenticated custody, not the supplied mutable snapshot. Changing both evidence and external pin defeats this model. This module has no durable anti-replay, review expiration, trusted time, signing service, threshold signatures or distributed consensus. The ledger only resists rollback when its head is independently maintained. No automatic publication, revocation or approval.

## Operational status
Prototype and tests on draft PR only. GO-13 HOLD / DENY remain unchanged; manual security review and CI required before any release.
