# NEO-009 — Dual-control review evidence (DRAFT)

A pure offline verifier checks two Ed25519-signed review statements for a key-register transition. The signed, domain-separated message binds namespace, previous trusted (version,digest) pin and proposed (version,digest) pin. It requires two distinct reviewer IDs with separately trusted roles OWNER and SECURITY, checks both signatures and checks both registry digests.

**Critical:** This is evidence verification, not authorization. Every result contains `authorized:false`, including success. No write, merge, key activation, revocation broadcast or production access is performed. Private keys are generated only in isolated test fixtures and are never used by production code.

Trusted reviewer keys, roles, and pins MUST be supplied via authenticated independent custody. A user who controls the supplied reviewer list and pins can forge an apparent quorum. This module does not establish real identities, prove human intent, implement role enrollment/revocation, timestamp validity, signature expiry, multi-party threshold cryptography, or persistent replay protection. A replayed but valid prior review is possible if external custody permits the old pins. External monotonic registry pin enforcement and audit governance are required before any production process.
