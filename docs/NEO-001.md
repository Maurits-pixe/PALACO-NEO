# NEO-001 — local admission contract (DRAFT)

## Scope
Pure, dependency-free admission prototype for PALACO NEO / AETHER / BASTION.
This module has **no IO**, identity integration, authority, OS privileges, persistence, network, Bluetooth, or deployment capability.

## Contract
- `inspect`: READ_ONLY, never mutates.
- `prepare`: returns a proposed next snapshot only when phase=REVIEW, expected revision matches, and request ID is new.
- `execute` and `publish`: always DENY under GO-13 HOLD.
- Every malformed input, stale revision or replay: DENY.
- Caller must NOT treat `PREPARED` as authorization. Returned snapshots are not trusted durable state.

## Limitations / next hardening
- In-memory seenIds is **not** durable anti-replay. A trusted transactional store is required later.
- No cryptographic identity, signed audit receipts, cross-process concurrency, or OS sandbox.
- Request IDs are syntactically checked, not cryptographically unique.
- No production trust claims. Human review remains mandatory.
